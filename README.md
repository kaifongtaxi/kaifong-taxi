# 街坊的 Kaifong Taxi — clickable demo

走遍全港，街坊幫街坊 · *Every street, every ride, neighbours side by side*

A community-led idea for a Hong Kong taxi-hailing app: licensed taxis only, **0% commission** (drivers keep the whole fare), nothing to pay per trip, and open rules.

**This is a demo.** Nothing is booked, no driver is contacted and no payment is made. Taxis, drivers, jobs and payment codes are made up.

## What's real in the demo
- Place search: Hong Kong Government Address Lookup Service, plus a list of common place names (coordinates from OpenStreetMap).
- Route options: OpenStreetMap routing (OSRM).
- Live tunnel journey times: Transport Department open data.
- Fares: the official taxi tariff (to be re-checked before real use).

## Run it
Open `index.html` in a browser, or serve the folder with any static web server. No build step.
